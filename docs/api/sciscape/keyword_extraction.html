def normalize_keywords( top_df: pandas.core.frame.DataFrame, builtin_aliases: Mapping[str, str], stopwords: Optional[Set[str]] = None, max_edit_distance: int = 2, min_frequency_ratio: float = 0.01, plural_merge_enabled: bool = True) -> pandas.core.frame.DataFrame:

Post-top-K keyword normalization.

Steps:

  1. Expand known abbreviations (builtin_aliases)
  2. Normalize notation (Greek letters, hyphens) 2b. Merge plural forms into singular (phrase-level)
  3. Merge near-duplicates by edit distance within each cluster

Returns a new DataFrame with normalized terms and merged frequencies.
